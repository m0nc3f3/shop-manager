# StockFlow - Application de Gestion de Magasin

Application de gestion de magasin avec interface graphique PyQt5.

## Fonctionnalites

- Gestion des produits (ajout, modification, suppression)
- Gestion des ventes avec calcul automatique du total
- Suivi du stock en temps reel
- Statistiques de ventes (chiffre d'affaires, produit star, top 5)
- Recherche de produits par nom ou categorie
- Base de donnees SQLite integree

## Installation

```bash
python -m venv venv
source venv/bin/activate   # Sur Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Utilisation

```bash
python main.py
```

## Technologies

- Python 3
- PyQt5 (interface graphique)
- SQLite (base de donnees)
